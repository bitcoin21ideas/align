# Workflows

This directory contains n8n workflow definitions for the Align pipeline.

---

## Files

### `walks-processing.json`

The main pipeline workflow. Import this directly into n8n.

**What it does:**
1. Receives an audio file via webhook (triggered by iOS Shortcut)
2. Sends the audio to Deepgram Nova-3 for transcription
3. Reads `prompts/gemini-main.md` from this repo (live, at runtime)
4. Reads the current `handover/rolling-handover.md` from the storage repo
5. Assembles the Gemini prompt: today's date + rolling handover + transcript
6. Sends the prompt to Gemini Flash and receives four delimited outputs
7. Splits on `===ROLLING_UPDATE===`, `===ARCHIVE_ENTRIES===`, `===MEMORY_ENTRIES===`
8. Writes the outputs to GitHub in parallel:
   - `walks/YYYY-MM-DD.md` — daily note (create or append)
   - `handover/rolling-handover.md` — overwrite
   - `handover/archive.md` — append
   - `memory/YYYY-MM.md` — append only when Gemini returns memory entries
   - `memory/memory-index.md` — append derived index lines only when memory entries exist

**Two GitHub repositories are required:**
- **This repo** (Align) — read at runtime to fetch `prompts/gemini-main.md`
- **A private storage repo** — read/write for all walk outputs (walks/, handover/, memory/)

A single GitHub personal access token covering both repos is sufficient.

**Values and credentials required:**

| Value | Where to configure it |
|---|---|
| Deepgram API key | n8n HTTP Header Auth credential |
| Google AI API key | n8n Gemini credential |
| GitHub token | n8n GitHub credential with read access to this repo and read/write access to the storage repo |
| Align repo | `Get prompt` GitHub node repository selector |
| Storage repo | All storage GitHub node repository selectors |

The current public workflow template uses n8n credentials and GitHub node
repository selectors. It is not env-driven yet; after import, open the GitHub nodes and reselect the correct repositories.

**Gemini prompt:** managed in `prompts/gemini-main.md`. The workflow reads this file at runtime — do not edit the prompt inside the workflow JSON directly.

## Importing into n8n

1. Open your n8n instance
2. Go to **Workflows → Import from file**
3. Select `walks-processing.json`
4. Configure credentials for Deepgram, Google AI, and GitHub
5. Configure Webhook node authentication before activation
6. Set a new random webhook path
7. Reselect the Align repo in `Get prompt` and the storage repo in all storage GitHub nodes
8. Activate the workflow

The webhook URL is generated by n8n on activation. Update your iOS Shortcut with this URL and the required auth header.

## Updating the public workflow JSON

`workflows/walks-processing.json` is a sanitized public template. Do not commit a raw export from your live n8n instance directly.

Local raw exports belong in `workflows/.local/`, which is gitignored.

### n8n UI steps

1. Open n8n.
2. Open the live **Align Recording to GitHub** workflow.
3. Make and save your workflow changes.
4. Use the workflow menu (`...`) and choose **Download** / **Export**.
5. Save the downloaded JSON as:
   `workflows/.local/walks-processing.raw.json`
6. From the repo root, run:

```bash
node scripts/sanitize-n8n-workflow.mjs
node scripts/check-public-workflow.mjs
```

The sanitizer writes the public template to `workflows/walks-processing.json`.
The checker fails if the public JSON still contains live credential names,
credential IDs, webhook IDs, private repo references, or token-shaped secrets.

For extra local-only checks, copy `.env.example` to `.env` and fill the
`PUBLIC_WORKFLOW_FORBIDDEN_TEXT_*` values with repo names or credential
labels that should never appear in the public workflow export. `.env` is
gitignored; the checker reports only the variable name that matched.

After sanitizing, review the diff before committing:

```bash
git diff -- workflows/walks-processing.json
```

### What the sanitizer changes

- Removes n8n `webhookId` metadata.
- Replaces credential IDs and credential names with placeholders.
- Replaces GitHub owner, repository, and cached repository URLs with placeholders.
- Replaces the webhook path with `replace-with-random-webhook-path`.
- Writes stable two-space formatted JSON for readable diffs.

When importing the public template into n8n, reselect credentials and
repositories in the UI before activating the workflow.

## Planned workflows

**`discord-capture.json`** — triggered by a message in `#quick-capture`.
Runs the same pipeline with text substituted for the transcript, skipping
the Deepgram step.

**`discord-query.json`** — triggered by a message in `#ask`. Reads
memory and note files from GitHub, passes them to Gemini with a query
prompt, and replies in Discord.

**`weekly-digest.json`** — scheduled Sunday run. Reads the past 7 daily
notes and current month's memory file, posts a synthesis to `#weekly-digest`.

See [docs/discord-design.md](../docs/discord-design.md) for the design
spec on all Discord workflows.
